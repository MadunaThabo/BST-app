Things you already know (quick recap)

• Comparing two numbers: a < b, a > b. • A node is an object holding a value plus references to other nodes — you met this with linked lists. • A reference can be null (empty).

1 · What does a tree look like?

A binary tree is made of nodes. Each node holds one value and has up to two children: a left child and a right child.

Three words you need:

  • Root — the single node at the top; the entry point.
  • Leaf — a node with no children.
  • Subtree — a node together with everything below it. The left child of the root, plus all of its descendants, is the root's left subtree.

That's it: a linked list where each node can point to two next nodes instead of one.

2 · The one rule that makes it a search tree

Everything in a node's LEFT subtree is smaller than the node. Everything in its RIGHT subtree is larger. This holds for every node, not just the root.

So if you're looking for 20 and you're standing at 50, you only ever need to look left. The entire right half of the tree is ignored — that's the phone-book trick.

✅ Valid BST

Check 30's right child: 40 > 30 ✓ and 40 < 50 ✓ (it's in 50's left subtree).

❌ Not a BST

60 is in 50's left subtree but 60 > 50. The rule is broken even though 60 > 30 looks fine locally.

Duplicates? In this app we don't allow them — inserting a value that's already there does nothing. (Your lecturer may choose a different convention.)

3 · Watch: inserting a value

The algorithm is three lines long. Start at the root; compare; go left if smaller, right if larger; when you reach an empty spot, put the new node there.

6 · Why does insertion order matter?

Insert the same seven numbers in two different orders and compare the trees.

Order: 4, 2, 6, 1, 3, 5, 7

Height 3. Finding any value takes at most 3 comparisons.

Order: 1, 2, 3, 4, 5, 6, 7

Height 7 — it's just a linked list in disguise. Finding 7 takes 7 comparisons. The phone-book trick is gone.

A tree whose height stays small is called balanced. Your lecture will show how trees like AVL and Red-Black trees keep themselves balanced no matter what order the values arrive in — and how to delete values, which this app skipped.
